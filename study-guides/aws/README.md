# AWS Deep Study Guides

This directory is the canonical AWS learning library maintained by the **DSA + AWS Guide Enrichment** scheduled pipeline.

## Goals

Each guide should be self-contained and teach from first principles:

- legacy/on-premise problem and flow
- beginner mental model
- internal working
- step-by-step packet/request/data flow
- realistic examples and dry runs
- original diagrams/images
- failure scenarios and troubleshooting
- security, performance, cost, and trade-offs
- AWS implementation and mappings
- interview questions and hands-on exercises
- matching Markdown and mobile-friendly HTML

## Structure

- `networking/` — Internet, Wi-Fi, mobile data, ISP routing, DNS, TCP/TLS/HTTP, NAT, firewalls, legacy data center, AWS VPC packet flow, troubleshooting.
- `core/` — AWS fundamentals and shared concepts.
- `modules/` — broad service-family learning modules.
- `components/` — focused service/component deep dives.
- `assets/` — educational diagrams and supporting visual assets.
