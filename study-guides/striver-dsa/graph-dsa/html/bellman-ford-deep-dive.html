Bellman-Ford: Negative Edges, Relaxation & Negative Cycles

Memory trick: Relax every edge V-1 times; one more improvement means a reachable negative cycle.

Source boundary: Topic placement follows the Striver/Take U Forward graph sequence. Proof expansions, examples, Java engineering notes and memory aids are additional study material, verified against Take U Forward and CP-Algorithms. This standalone page is mobile-friendly and browser-searchable.

Problem and pattern

Compute single-source shortest distances in a weighted directed graph even when edges may be negative. A reachable negative cycle makes finite shortest paths undefined for affected vertices.

Choose Bellman-Ford for single-source shortest path plus negative edges or reachable-negative-cycle detection. Prefer Dijkstra for nonnegative weights, topological relaxation for DAGs, and Floyd-Warshall for many all-pairs workloads.

Invariant and relaxation

dist[v] is the best source-to-v cost discovered so far. After pass i, shortest paths requiring at most i edges have been propagated.

if dist[u] != INF and dist[u] + w < dist[v]:
    dist[v] = dist[u] + w

Java implementation

record Edge(int from, int to, long weight) {}

long[] d = new long[n];
Arrays.fill(d, INF);
d[source] = 0;

for (int pass = 1; pass <= n - 1; pass++) {
    boolean changed = false;
    for (Edge e : edges) {
        if (d[e.from()] == INF) continue;
        long candidate = d[e.from()] + e.weight();
        if (candidate < d[e.to()]) {
            d[e.to()] = candidate;
            changed = true;
        }
    }
    if (!changed) break;
}

boolean negativeCycle = false;
for (Edge e : edges) {
    if (d[e.from()] != INF &&
        d[e.from()] + e.weight() < d[e.to()]) {
        negativeCycle = true;
        break;
    }
}

Correctness

Initialization: source is zero; all others are unknown. Maintenance: after pass i-1, shortest paths of at most i-1 edges are represented; scanning the final edge of an i-edge path propagates its value. Termination: a finite simple shortest path has at most V-1 edges. A reachable improvement afterward signals a reachable negative cycle.

Complexity

At most V-1 passes times E edge scans gives O(VE) time and O(V) extra distance storage. Early stopping helps favorable inputs but not the worst-case bound.

Boundary conditions

  • V=1 needs zero passes.
  • Unreachable vertices stay INF.
  • Unreachable negative cycles do not affect source-specific detection.
  • A reachable negative self-loop is a negative cycle.
  • Parallel edges are naturally handled.
  • Use long when int can overflow.

Repeated work and memoization

This is not memoized recursion. The distance array is compressed reusable state: it avoids path enumeration and stores the best known summary for each vertex.

Common mistakes

  1. Using Dijkstra with negative edges.
  2. Omitting the INF guard.
  3. Running too few passes.
  4. Confusing reachable and unreachable negative cycles.
  5. Ignoring overflow.

Comparison map

equal weights -> BFS
0/1 weights -> 0-1 BFS
DAG -> topological relaxation
nonnegative -> Dijkstra
negative edges -> Bellman-Ford
all pairs -> Floyd-Warshall
